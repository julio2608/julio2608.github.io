Política de Privacidade — SMB Fácil

Última atualização: 8 de outubro de 2026

O SMB Fácil é um aplicativo para Android que permite compartilhar, por meio do protocolo SMB, uma pasta escolhida pelo usuário na rede local, possibilitando o acesso aos arquivos a partir de computadores e outros dispositivos conectados à mesma rede.

1. Informações armazenadas pelo aplicativo

Para funcionar, o SMB Fácil pode armazenar localmente no dispositivo:

  • nome de usuário definido pelo usuário;
  • senha definida pelo usuário para o servidor SMB;
  • identificação da pasta selecionada para compartilhamento;
  • nome da pasta selecionada;
  • preferências relacionadas ao modo de compartilhamento.

Essas informações são utilizadas para configurar e manter o servidor SMB no próprio dispositivo. O SMB Fácil não envia esses dados para servidores próprios ou terceiros.

2. Arquivos e pastas

O usuário escolhe explicitamente a pasta que deseja compartilhar. O aplicativo utiliza essa pasta para disponibilizar seus arquivos através do servidor SMB local.

O aplicativo não envia os arquivos para a internet ou para um serviço de armazenamento em nuvem.

3. Rede e endereço IP

O SMB Fácil utiliza a conexão de rede do dispositivo para disponibilizar o servidor SMB. O endereço IP local pode ser exibido no aplicativo para que o usuário saiba como acessar o compartilhamento a partir de outro dispositivo na mesma rede.

O endereço IP é utilizado localmente para a finalidade de conexão ao servidor SMB e não é enviado pelo aplicativo a um servidor externo.

4. Compartilhamento de dados

O SMB Fácil não vende, aluga ou compartilha informações pessoais do usuário com terceiros para fins de publicidade ou marketing.

O aplicativo não possui anúncios e não utiliza os dados armazenados para publicidade personalizada.

5. Internet

Embora o aplicativo utilize permissões de rede necessárias para executar o servidor SMB, sua finalidade principal é permitir o compartilhamento de arquivos dentro da rede local do usuário.

O aplicativo não depende de uma conta em um serviço externo para executar o servidor SMB.

6. Segurança

O usuário é responsável por escolher uma senha adequada e por compartilhar a pasta somente com pessoas e dispositivos de confiança. O servidor deve ser utilizado em redes sob controle ou confiança do usuário.

7. Crianças

O SMB Fácil não é direcionado especificamente a crianças e não coleta intencionalmente dados pessoais de crianças.

8. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada quando necessário para refletir alterações no aplicativo, nos recursos oferecidos ou nas exigências legais aplicáveis. A versão atualizada será disponibilizada nesta página.

9. Contato

Para dúvidas sobre esta Política de Privacidade ou sobre o tratamento de dados no SMB Fácil, entre em contato pelo canal de suporte disponibilizado na página do aplicativo no Google Play.

10. Consentimento

Ao utilizar o SMB Fácil, o usuário reconhece esta Política de Privacidade e as práticas descritas nela.
